## 🧠 Algorithms

### Minimax

The Minimax algorithm is a decision-making algorithm used in artificial intelligence and game playing. It evaluates possible moves and selects the move that provides the best possible outcome for the AI while assuming that the opponent also plays optimally.

### Alpha-Beta Pruning

Alpha-Beta Pruning is an optimization of the Minimax algorithm. It reduces the number of game states that need to be evaluated by pruning branches that cannot affect the final decision.

## 🎮 Game

The project implements Tic Tac Toe where the AI uses game-playing algorithms to determine its moves.
